## How to play our game!

- Click on the link above labeled Game Website Link.
- This will take you to our homepage.
- If you prefer your visual settings to be on Dark Mode, you can use the toggle to change lighting modes on the bottom right corner.
- From here you can click the Randomize Game to automatically take you into one the two games we have developed.
- Or you can select which game you want to play by clicking play in each game's card. 
- Both games have multiple versions of themselves:
  - For the Matching Game you can select your theme: Default, or Cultures.
  - For the Sequence Game you can toggle the difficulty of the game by toggling the difficulty button.
- Once you have your set preferences both games can only begin after you click on the Start Game button which will enable all functionalities.
- Once you have played the game atleast once you can access your top/best game log in the records page which can be accessed from clicking the trophy icon on the bottom left corner of each of our pages.
- Once in the records menu you can select which game's records you want to view using the drop down.
  - Once selected the Matching game can sort by best time or best moves, and the Sequence Game can be sorted by difficulty.
- At any point to return back to the homepage just click on the arrow on the top left corner of each game/record page.
